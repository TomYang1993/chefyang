# Images to generate

One hero image per recipe. Everything else (3 Pinterest pins and an Instagram 4:5 crop) is made from it by `npm run pins`.

Rules for every image: photorealistic but clearly styled food photography, no text, no hands, no people, no brand logos. Keep the dish in the middle so the 4:5 Instagram crop works.
